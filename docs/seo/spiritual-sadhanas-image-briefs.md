## Image Count Decision

Use 3 main images for implementation first.

Reason:

- The current modality page template already supports a clean 3-image rhythm: hero image, practice clarity image, and retreat experience image.
- Adding too many images can make the page feel repetitive because Yoga, Meditation, Sound, Panchakarma and Chakra pages already follow a similar structure.
- For SXO, 3 strong images are enough if they explain the practice clearly.

Optional 4th image can be generated only if we decide to add a new visual block later. It is not required for the first implementation.

## Global Visual Rules

- Keep the images realistic and human.
- No glowing light, aura, supernatural effects, levitation or fantasy styling.
- No guru worship scene.
- No forced religious conversion cues.
- No dramatic fire ritual or occult visual language.
- No medical, therapy or clinical scene.
- Use a calm Rishikesh retreat setting: wooden floors, white curtains, garden, veranda, foothills, natural light.
- People should look grounded, quiet and natural.
- No visible text, logo, watermark or UI element inside the image.
- Leave enough negative space for responsive crop.
- Use soft natural colors: off-white, warm wood, muted green, light beige and calm earth tones.
